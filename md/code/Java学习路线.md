# Java 学习路线规划

> 目标：掌握 Java 核心 → Spring Boot 全栈开发 → AI 应用集成
> 总预计时间：4-6 个月（每天 2-3 小时）

---

## 第一阶段：Java 基础（2-3 周）

### 目标：建立 Java 编程思维，掌握核心语法

| 知识点    | 内容                             | 预计时间  |
| ------ | ------------------------------ | ----- |
| 环境搭建   | IDEA / Eclipse、 JDK 安装配置       | 1 天   |
| 基础语法   | 变量、数据类型、运算符、流程控制               | 2-3 天 |
| 面向对象   | 类、对象、继承、多态、接口、抽象类              | 3-4 天 |
| 核心 API | String、集合框架（List/Set/Map）、异常处理 | 3-4 天 |
| 常用类库   | IO 流、泛型、注解、枚举、Lambda           | 2-3 天 |
| 并发基础   | Thread、Runnable、线程同步、volatile  | 2-3 天 |

### 里程碑
- 能独立实现 CRUD 控制台程序
- 理解 OOP 四大特性并灵活运用
- 掌握集合框架选择与使用

### 资源推荐
- 书籍：《Java 核心技术卷 I》《Effective Java》
- 视频：B站 狂神说 Java / 韩顺平 Java 零基础

---

## 第二阶段：Java Web 基础（2-3 周）

### 目标：掌握 Web 开发核心 技术（B/S 架构）

| 知识点 | 内容 | 预计时间 |
|--------|------|----------|
| HTTP 协议 | 请求/响应结构、状态码、请求方法 | 1 天 |
| Servlet | 生命周期、会话管理（Cookie/Session） | 2-3 天 |
| MVC 模式 | Model/View/Controller 分离思想 | 1-2 天 |
| 数据库 | MySQL 基础、SQL 增删改查、JDBC | 3-4 天 |
| 前端基础 | HTML/CSS/JavaScript 入门 | 2-3 天 |

### 里程碑
- 能实现简单的用户登录注册功能
- 理解前后端交互流程
- 掌握 JDBC 操作数据库

---

## 第三阶段：SSM 框架（3-4 周）

### 目标：掌握传统企业级开发主流框架

| 知识点        | 内容                   | 预计时间  |
| ---------- | -------------------- | ----- |
| Spring     | IoC/DI、AOP、Bean 生命周期 | 3-4 天 |
| Spring MVC | 控制器、视图解析、数据绑定        | 2-3 天 |
| MyBatis    | 映射文件、动态 SQL、缓存       | 2-3 天 |
| 整合练习       | SSM 整合项目（图书管理系统）     | 4-5 天 |

### 里程碑
- 能独立完成 SSM 整合项目
- 理解 Spring IoC/AOP 核心原理

---

## 第四阶段：Spring Boot + 微服务（4-6 周）⭐

### 目标：掌握现代 Java 开发核心技能

| 知识点 | 内容 | 预计时间 |
|--------|------|----------|
| Spring Boot 基础 | 自动配置、起步依赖、 Actuator | 2-3 天 |
| Web 开发 | RESTful API、异常处理、参数校验 | 3-4 天 |
| 数据访问 | JPA/MyBatis-Plus、多数据源、事务 | 3-4 天 |
| 安全框架 | Spring Security / Shiro | 3-4 天 |
| 缓存 | Redis 基础、Spring Cache、分布式缓存 | 3-4 天 |
| 消息队列 | RabbitMQ / Kafka 基础 | 2-3 天 |
| 微服务 | Nacos 注册/配置中心、Feign 远程调用、Gateway | 3-4 天 |
| 容器化 | Docker 基础、K8S 入门 | 2-3 天 |
| 项目实战 | 电商/博客/后台管理等完整项目 | 1-2 周 |

### 里程碑
- 能独立构建 Spring Boot 微服务项目
- 掌握分布式系统常见问题和解决方案
- 完成 1-2 个完整项目

---

## 第五阶段：AI 应用开发（3-4 周）🤖

### 目标：掌握 AI 能力集成到 Java 应用

| 知识点       | 内容                           | 预计时间  |
| --------- | ---------------------------- | ----- |
| AI 基础概念   | 大模型基本原理、Prompt 工程            | 1-2 天 |
| AI API 调用 | OpenAI API / 文心一言 / 通义千问     | 2-3 天 |
| Spring AI | Spring AI 框架使用（Java 对接 AI）   | 3-4 天 |
| RAG 知识库   | 向量数据库（Milvus/Pinecone）、文档检索  | 3-4 天 |
| Agent 开发  | LangChain4j、工具调用、Multi-Agent | 2-3 天 |
| 项目实战      | AI 问答助手、智能客服、文档处理等           | 1 周+  |

### 里程碑
- 能将大模型能力集成到 Spring Boot 应用
- 理解 RAG 架构并实现本地知识库问答
- 完成 AI 应用项目

---

```
SSM 框架 (3-4周)
    ↓
Spring Boot + 微服务 (4-6周) ⭐ 核心
    ↓

```

## 每日学习建议

| 时段            | 内容           |
| ------------- | ------------ |
| 工作日晚上（1.5-2h） | 看视频/文档学习新知识  |
| 周末（3-4h）      | 敲代码练习 + 项目实战 |
| 每日碎片时间        | 刷题巩固、逛技术社区   |

---

## 关键提醒

1. **不要只看视频** — 敲代码比看视频重要 10 倍
2. **多做项目** — 2-3 个完整项目 > 100 个 Demo
3. **学会提问** — 善用 Google、Stack Overflow、AI 助手
4. **做好笔记** — 整理知识体系，输出倒逼输入
5. **第四阶段是分水岭** — Spring Boot 掌握程度决定薪资水平
