### 基础语法
#### 二分查找
左边界二分查找:
- `left`：**第一个 ≥ target 的位置**，正好是插入位置
- `right`：最后一个 ＜ target 的位置
- 循环条件：`left <= right`
- 最后一定 `left = right + 1`，**返回 left**
```java
//关键点在于while中的条件判断和第一个if
class Solution {
    public int searchInsert(int[] nums, int target) {
        int left = 0, right = nums.length - 1;
        while (left <= right) {
            int mid = (left + right) / 2;
            if (nums[mid] < target) {
                left = mid + 1;
            } else {
                right = mid - 1;
            }
        }
        return left;
    }
}
```
##### 二分查找平方根
与二分查找模板有三个不同
1.r值
2.if判断条件
3.mid值计算方法
```java
class Solution {
    public int mySqrt(int x) {
        int l=0,r=x,ans=-1;
        while(l<=r){
            int mid = l+(r-l)/2;
            if((long)mid*mid<=x ){
                ans=mid;
                l=mid+1;
            }
            else{
                r=mid-1;
            }
        }
        return ans;
    }
}
```

### 前缀和
前缀和模板-可求数组中任意两个位置中的和
```java
// nums 原数组
int[] nums = {1,2,3,4,5};
int n = nums.length;
// 构造前缀和数组，长度 n+1，preSum[0] = 0
int[] preSum = new int[n + 1];
for (int i = 0; i < n; i++) {
    preSum[i + 1] = preSum[i] + nums[i];
} 
// 查询 [left, right] 下标区间和 （从0开始）
int left = 1, right = 3;
int sum = preSum[right + 1] - preSum[left];
System.out.println(sum);
```

#### 二维前缀和
二维前缀和模板-求子矩阵元素和
```java
// matrix 原二维数组
int[][] matrix = {
    {1, 2, 3},
    {4, 5, 6},
    {7, 8, 9}
};
int m = matrix.length, n = matrix[0].length;
// 构造二维前缀和数组，长度 (m+1) x (n+1)，preSum[0][*] 和 preSum[*][0] 为 0
int[][] preSum = new int[m + 1][n + 1];
for (int i = 1; i <= m; i++) {
    for (int j = 1; j <= n; j++) {
        preSum[i][j] = preSum[i-1][j] + preSum[i][j-1] - preSum[i-1][j-1] + matrix[i-1][j-1];
    }
}
// 查询 (x1,y1) 到 (x2,y2) 子矩阵和 （左上角(x1,y1)，右下角(x2,y2)，从0开始，含两端）
int x1 = 1, y1 = 1, x2 = 2, y2 = 2;
int sum = preSum[x2+1][y2+1] - preSum[x1][y2+1] - preSum[x2+1][y1] + preSum[x1][y1];
System.out.println(sum);
```
